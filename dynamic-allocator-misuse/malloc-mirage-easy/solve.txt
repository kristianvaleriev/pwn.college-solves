We make two allocs (with the same size as of flag's buffer) so that when freed the first one will have non-zero next field.
When the flag buffer is allocated it returns the address of the first element in the tchace_perthread_struct list.
We then free it again, thus overwriting the first two 8 byte entries of allocated space for the flag's buffer, with
tcache metadata (next and key entry pointers).
